# Gestor de Tareas — DeTodoEc

Página estática lista para GitHub Pages.

## Funciones
- Tareas con imagen cuadrada.
- Tema claro/oscuro.
- Cliente, responsable del trabajo y persona que tomó el pedido.
- Valor total, costo/materiales, abonos y saldo.
- Cálculo de ganancia y reparto 70% / 30%.
- Estados: Pendiente, En proceso, Terminado y Entregado.
- Filtros rápidos por estado.
- Archivo de pedidos entregados y opción de restaurarlos.
- Icono/logo personalizable y favicon.
- Diseño a pantalla completa y adaptable a celular.
- Datos guardados en `localStorage` del navegador.

## Publicar en GitHub Pages
Sube `index.html`, `styles.css` y `app.js` a la raíz del repositorio. En Settings → Pages usa `Deploy from a branch`, rama `main`, carpeta `/ (root)`.
